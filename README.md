# Aileron（エルロン）

**Aileron（エルロン）公式サイト:** https://haruto9519-cell.github.io/Aileron/

Aileron is an independently operated Japanese web-services brand. It plans and operates digital services for travel planning, life transitions, and safer online shopping.

## 公式サービス

- **旅比べ** — 旅行予算や行き先から旅行計画を考えるサービス: https://tabi-hikaku.pages.dev/
- **LIFE SHIFT** — 進学・就職・引越しなど、暮らしの転機に必要な準備を整理するサービス: https://lifeshift.pages.dev/
- **買いまも** — ネット通販の購入前確認や購入後の情報整理を支援するサービス: https://haruto9519-cell.github.io/Aileron/kaimamo/

## 事業者向け支援

ホテル・旅館など観光事業者向けに、Webサイトの情報整理や集客改善案づくりを行っています。

詳細: https://haruto9519-cell.github.io/Aileron/tourism-marketing-support.html
