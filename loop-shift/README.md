# LOOP SHIFT — Aileron Game Studio

スマートフォン・PCのブラウザで遊べるパズルゲームの試作版です。

## 遊び方
- パネルをタップ／クリックして90度回転させます。
- STARTからGOALまでつながる道を作ります。
- 12手以内に完成させることを目指します。
- ベスト記録はこの端末のブラウザ内に保存されます。

## 開発状況
- Prototype 0.1
- 1ステージ、回転操作、接続判定、手数制限、ヒント、端末内ベスト記録を実装
- サーバー・外部API・ログイン不要
