トラブル対処ガイド

状況を整理し、適切な相談先につなげるための基本情報です。

📦

商品が届かない・配送が遅い

  1. 注文履歴と発送通知を確認する
  2. ショップの公式窓口へ状況を問い合わせる
  3. 注文番号・支払い記録・連絡履歴を保存する
  4. 解決しない場合は消費生活相談窓口へ相談する
↩️

返品・返金で困っている

  1. 注文時の返品・キャンセル条件を確認する
  2. 商品状態やショップとのやり取りを記録する
  3. ショップの正式な窓口から申し出る
  4. 条件や対応に疑問があれば公的窓口に相談する
💳

身に覚えのない請求がある

  1. 請求元・利用明細・注文履歴を確認する
  2. カード会社や決済サービスの公式窓口に連絡する
  3. 不審な連絡先には返信せず、公式アプリ等から確認する
  4. 必要に応じて消費生活相談窓口へ相談する
🔁

サブスクを解約したい

  1. 契約先と契約内容を確認する
  2. 公式サイト・アプリの解約手順を確認する
  3. 解約完了画面や受付メールを保存する
  4. 請求が続く場合は決済会社・相談窓口に確認する

KAIMAMO PURCHASE SUPPORT

買いまもは、ネット通販の購入前後をまとめて管理するサービスです

ネット通販では、購入先の情報を確認すること、注文内容を記録すること、返品や保証の期限を把握することが大切です。買いまもは、こうした買い物に関する確認や記録を、ひとつの画面で整理できる購入サポートWebアプリです。

買いまもでできること

購入前のショップ確認

ショップのURLや運営者情報、連絡先、返品条件など、購入前に確認したい項目をチェックリストで整理できます。自動的な詐欺判定や安全保証を行うものではありません。

ネット通販の購入記録

商品名、購入先、購入日、注文に関するメモを記録し、あとから購入内容を振り返りやすくします。

返品期限・保証期限の管理

返品の申出期限や保証期限など、自分で登録した日付を一覧で確認できます。期限の条件は購入先や商品ごとに確認してください。

定期購入・トラブル対応の整理

定期購入の次回更新日、販売者との連絡内容、商品到着時の確認事項などをまとめて管理できます。

ネット通販で購入したら記録しておきたい項目

  • ショップ名・販売事業者名・問い合わせ先
  • 商品名・注文番号・購入日・支払金額
  • 返品・交換の条件と申出期限
  • 保証期間と保証を受けるための条件
  • 定期購入の次回更新日・解約方法
  • 販売者への問い合わせ内容と返信

購入時の画面や注文確認メールも、必要に応じて別途保管しましょう。買いまもは記録を整理するための補助ツールであり、販売者の規約や法律上の判断に代わるものではありません。

返品・返金の条件を確認したい方へ

通信販売の返品条件は、購入先が表示している返品特約や商品・取引の状況によって異なります。返品を考えている場合は、まず注文時の表示や販売者の公式案内を確認してください。

  • ネット通販の返品・返金方法｜返品期限と確認ポイント
  • 怪しい通販サイトの見分け方｜注文前の確認ポイント
  • サブスクの解約方法｜定期購入をやめる前の確認手順
  • ネット通販トラブルにあったら？注文後の確認手順と相談先

よくある質問

買いまもは購入先の安全性を自動判定しますか？

いいえ。確認項目を整理するチェックリストです。入力内容やショップの安全性を自動調査・保証するものではありません。

購入記録はどこに保存されますか？

購入記録などは利用中のブラウザ内に保存されます。サーバー同期はありません。同じ端末・同じブラウザで利用し、必要に応じてバックアップしてください。

返品期限や保証期限を自動で調べてくれますか？

いいえ。購入先や商品ごとの条件を確認し、利用者自身が期限を登録して管理する仕組みです。

スマートフォンでも使えますか？

Webブラウザから利用できます。端末やブラウザのデータを削除すると、保存した記録が失われる場合があります。

買いまもは購入に関する情報や期限を整理するためのβ版サービスです。購入先の安全性、返品・返金の可否、期限内の対応、損害の回避を保証するものではありません。パスワード、決済情報、本人確認書類などの機密情報は入力しないでください。

ネット通販で困ったときの無料ガイド

購入前の確認から、返品・返金、定期購入、注文後のトラブルまで。公的機関の情報を参考に、確認する順番をまとめています。

怪しい通販サイトの見分け方 → URL・販売者情報・価格・支払い方法など、注文前の確認ポイント。 ネット通販の返品・返金方法 → 返品期限、返品特約、送料、販売者への連絡前に確認したいこと。 サブスクの解約方法 → 次回更新日、解約窓口、申出期限、手続き後に残す記録。 ネット通販トラブルの対処法 → 商品が届かない・違う商品が届いた・返金されないときの確認手順。

※一般的な情報提供です。個別の契約や返金の可否を判断・保証するものではありません。

買いまもについてよくある質問

買いまもでは何を管理できますか？

ネット通販の購入記録、返品・保証の期限、定期購入の次回更新日、ショップ確認のチェック内容などをまとめて管理できます。

購入記録や入力内容はどこに保存されますか？

このサービスでは、入力した記録を利用中の端末のブラウザー内に保存します。別の端末やブラウザーとは自動で同期されません。ブラウザーのデータを消去すると記録も失われる場合があります。

ショップ確認で安全な通販サイトか断定できますか？

いいえ。チェック項目は購入前の確認を助けるもので、安全性を保証するものではありません。販売者情報や返品条件を確認し、不安がある場合は購入を見送ることも検討してください。

返品期限や返金の可否を判断してくれますか？

個別の返品・返金の可否を判定するサービスではありません。購入時の返品特約や販売者の公式案内を確認してください。困ったときは消費者ホットライン188などの公的相談窓口も利用できます。
