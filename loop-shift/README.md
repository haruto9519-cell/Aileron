# LOOP SHIFT — Aileron Game Studio

スマートフォン・PCのブラウザで遊べる、ルート接続パズルです。

## 遊び方
- STARTからGOALまで、青く光る道をつなぎます。
- パネルをタップ／クリックすると90度回転します。
- 手数を節約してクリアすると最大3スターを獲得できます。
- 全5ステージを順番に攻略します。
- クリア記録・解放状況・ベスト手数は利用中のブラウザに保存されます。

## 現在の機能
- スマートフォン／PC対応のレスポンシブ画面
- 5ステージと段階的なルート構成
- 手数制限、タイマー、ベスト手数
- 3段階スター評価とステージ解放
- リスタート、ヒント、効果音ON/OFF
- クリア結果の共有（対応ブラウザでは共有メニュー）
- サーバー、外部API、ログイン不要

## 公開版について
GitHub Pagesで公開する静的ブラウザゲームです。記録は端末・ブラウザ単位で保存され、オンラインランキングや端末間同期はまだありません。
